    Game logging

    checking…

    This app reads the game's log file, and the game only writes one when logging is on. Turning it on here sets Log=1 in eqclient.ini — what /log on does, but permanently and for every character.
    Set it with the game closed: EverQuest rewrites that file when it exits and would undo the change.

    Overlay

    Tabs

    Puts it back at its default size, top-right of this screen.

    Untick the tabs you don't use and they leave the overlay. Its title bar has a – button that rolls it up to just that bar, and a + to bring it back.
    Right-click that bar for the same settings without leaving the game: lock, tabs, opacity, text size.

    Hotkeys anywhere, even with the game focused: Ctrl+Shift+O show/hide · Ctrl+Shift+L lock/unlock.
    The overlay can only sit over the game in windowed or borderless display mode — exclusive fullscreen draws past every other window.
